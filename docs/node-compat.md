# Node module compatibility

Generated by `node tools/gen-node-compat.mjs`; `--check` fails on a stale file and both run in CI. Do not edit.

The dot is the pass rate of node's own `test-<area>-*.js` cases, passed out of RAN; skipped cases score neither way.
🟢 90%+ · 🟡 60%+ · 🟠 30%+ · 🔴 below · ⚪ nothing ran. A module that does not load is 🔴 whatever its cases did, and under 5 cases that ran the ceiling is 🟠.

Exports do not affect the dot: that column is the worklist, not a score.

The bun 1.3.10 column is this repo's own sweep over the identical files with `MILOJS_RUNTIME=$(which bun)`. The "bun says" column is what bun's published table claims for the same module. One is measured, the other is asserted, and they sit side by side on purpose: bun's 🟢 means the module is implemented, the dot here means node's cases pass.

Compare the two cells only through their skip counts: a smaller denominator flatters the rate. The whole-suite line under the table is the comparable form.
