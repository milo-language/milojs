# Contract: VM Coverage Report

`docs/conformance/vm-coverage.json`, generated by `tools/vm-coverage.mjs`, never
hand-edited. Fields: corpus (path + revision), milojs revision, totals { functionBodies,
loopBodies, compiledBodies, pct }, blockers: [{ construct, bodiesBlocked, note }] ranked
by bodiesBlocked desc.

- The admitted-construct table lives in the tool; a teeth case proves table entries
  actually compile (probe program per construct, witnessed by `MILOJS_VM_STATS=1`), so
  the static classification cannot drift from the compiler.
- `tools/check-vm-coverage.mjs` ratchets totals.pct: it may not go down (empty report or
  zero bodies = failure, per FR-008/SC-002 discipline).
- Published number quotes its denominator (21,617 function bodies at the current corpus
  revision); docs/status.md cites it through gen-facts like every other number.
